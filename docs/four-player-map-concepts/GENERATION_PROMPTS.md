# GPT Image 2 Generation Prompts

All concept and production masters in this overhaul were created with GPT Image 2 through Codex's built-in image-generation workflow. Concept images are proposal references. Runtime images are immutable source masters processed by `tools/process_assets.py`.

## Archipelago map concept

Use case: stylized-concept. Asset type: game environment concept art for a four-player RTS map proposal. Show four small starting islands at the four corners, each with a compact Stronghold and three Workers, connected by exactly one narrow Moon Bridge per island to one large resource-rich central continent. At the exact center, a majestic coiled Shenlong guards one luminous egg in a ceremonial jade clearing. Place multiple Yaoguai caves and abundant Jade, Essence shrines, forests, and wildlife across the center. Use a high top-down isometric view, painterly original Chinese-mythic RTS styling, celadon water, jade meadow, inkstone ridges, moonstone bridges, and a jade-and-gold central glow. No UI, labels, text, logos, watermarks, extra islands, or extra bridges.

## Shenlong objective concept

Use case: stylized-concept. Asset type: game objective concept art. Show the full objective loop in one wide isometric vignette: a Shenlong guarding an egg in a jade shrine, the defeated guardian, one Worker carrying the egg across a Moon Bridge, a distant corner Stronghold, and one ghosted allied Shenlong hatch promise. Transition from tense jade lightning at the shrine to hopeful gold at the base. Exactly one Shenlong, one physical egg, one carrier, one bridge, and one destination Stronghold. No UI, labels, text, logos, or watermarks.

## Production Shenlong master

Use case: stylized-concept. Asset type: isometric RTS unit sprite master. Create one complete, wingless Chinese-style Shenlong in a compact coiled guardian pose, head raised and facing screen-right. Use jade-green scales, pale antler-like horns, long whiskers, gold-edged dorsal fins, four clawed legs, and a subtle pearl glow. Preserve a crisp full-body silhouette with generous padding. The final background correction changes only the background to a perfectly uniform #FF00FF chroma field for deterministic extraction. No scenery, egg, text, logo, or watermark.
