# Cursor Generation Prompts

All 17 cursor masters were generated with the built-in GPT Image 2 workflow as separate transparent PNG assets.

## Shared prompt

```text
Use case: stylized-concept
Asset type: real-time strategy game mouse cursor master, transparent PNG
Scene/backdrop: genuinely transparent background, no panel, no tile, no scene
Style/medium: hand-painted game UI cursor, crisp charcoal-ink outline, polished celadon jade with restrained antique-gold accents, Chinese mythology strategy game aesthetic, legible when reduced to 64 by 64 pixels
Composition/framing: one isolated compact glyph centered with generous transparent padding; no cropped edges
Constraints: exactly one icon; actual alpha transparency; strong simple silhouette; no shadow outside the icon; no text; no letters; no logos; no watermark; no border; no background shape
Avoid: photorealism, cursor screenshot, multiple icons, decorative scene, checkerboard transparency pattern
```
