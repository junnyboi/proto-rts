# Command Indicator Generation Prompts

The three command-indicator masters were generated as separate transparent PNG assets with the built-in GPT Image 2 workflow on 2 September 2026. They are immutable source masters; runtime derivatives are created only by `tools/process_assets.py`.

## Destination flag

```text
Use case: stylized-concept
Asset type: real-time strategy game world-space command endpoint indicator, transparent PNG master
Primary request: one compact destination flag marker for a unit walking to explore a map tile
Scene/backdrop: genuinely transparent background, no panel, no tile, no scene
Subject: a single elegant antique-gold command flag on a short dark jade pole, the small banner curling once in the wind, planted into a tiny celadon waypoint bead
Style/medium: hand-painted game UI icon, crisp charcoal-ink outline, polished celadon jade and restrained antique gold, mythic Chinese strategy-game aesthetic, clean enough to remain legible at 48 pixels
Composition/framing: one isolated vertical glyph centered with generous transparent padding, complete uncropped silhouette
Lighting/mood: subtle warm highlight and restrained jade glow
Constraints: exactly one icon; actual alpha transparency; strong simple silhouette; no shadow outside the icon; no text; no letters; no logos; no watermark; no border; no background shape
Avoid: photorealism, multiple flags, cursor arrow, decorative scenery, checkerboard transparency pattern
```
